# 🚀 100 Days of DSA

Welcome to my **100 Days of Data Structures & Algorithms** journey.

This repository contains my daily DSA practice in **Java**, with a focus on understanding problem-solving patterns, writing clean solutions, analyzing time and space complexity, and preparing for coding interviews.

## 🎯 Goals

- Build strong DSA fundamentals
- Solve problems consistently for 100 days
- Learn multiple approaches wherever useful
- Improve time and space complexity analysis
- Strengthen problem-solving skills for coding interviews
- Maintain a public record of my learning journey

## 🛠️ Language & Tools

- **Language:** Java ☕
- **IDE:** VS Code
- **Platform:** LeetCode + company-specific problems
- **Version Control:** Git & GitHub

## 🧠 Problem-Solving Approach

For every problem, I try to follow this process:

1. **Understand the problem**
2. Identify the **constraints**
3. Think of the **brute-force approach**
4. Look for a better **pattern / data structure**
5. Implement the solution in Java
6. Analyze **Time Complexity**
7. Analyze **Space Complexity**
8. Test with normal and edge cases
9. Compare alternative approaches when applicable

## ⭐ Multiple Approaches

Whenever a problem has multiple useful solutions, I try to understand and implement them.

For example, **Find Duplicate Number** was explored using:

- XOR
- Floyd's Cycle Detection

And **Valid Anagram** was explored using:

- Sorting
- Frequency Array
- HashMap

The goal is not only to get the correct answer, but also to understand **why one approach is better than another under different constraints**.

## 📊 Complexity Matters

I am documenting complexity alongside my solutions:

```text

```

My focus is to gradually move from:

